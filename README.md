# 露營裝備清單

6 人・2 帳的露營裝備清單，做成手帳拼貼風格的「登山闖關」：勾完一區就往上爬一站，營火會點亮，還能到營火邊烤棉花糖。
純 HTML／CSS／JavaScript，全部寫在一個 `index.html` 裡，不需要後端、不用安裝或建置，放上 GitHub Pages 就能用。

![預覽圖](og-image.png)

## 功能

畫面下方有四個分頁：**山路／清單／營火／分享**。

- **上方固定列**：往下捲動時一直看得到
  - 郵戳顯示出發倒數（D-幾天），點一下到營火倒數
  - 「出發體力」：還沒打勾的項目會依「沒帶會怎樣」分成寒冷、淋濕、飢餓、摸黑、受傷、狼狽、沒情報，用不同顏色顯示在體力條上
  - 點狀態標籤會直接跳到還缺的那一項
  - 「公共 x/21」「行李 x/12」點一下跳到該區
- **山路**：登山路線圖，由下往上四個營地
  - 海岸營地＝先問營區、森林營地＝公共裝備、高山營地＝炊具、雪線營地＝個人行李
  - 吉祥物「寄居帳」（背著小帳篷當殼的寄居蟹）會照進度沿著步道橫著往上走；點牠會先縮回帳篷再探頭，順便給提示
  - 完成一區，那個營地的營火就會點亮
  - 全部勾完會抵達山頂，自動發射攻頂信號彈
  - 下方有 6 枚徽章：情報、搭營、伙房、背包、烤棉花糖、攻頂
- **清單**：手帳內頁，右邊的索引標籤切換四區，切換時有翻頁動畫
  - 插圖會跟著進度變化：帳篷從袋子到搭好插旗、鍋子冒熱氣、背包裝滿、手機問完營區
  - 打勾有手繪勾勾動畫，右下角的寄居帳會探頭揮鉗子；一區勾完會蓋「全部備妥」章
- **營火**：營火休息站
  - 寄居帳用大鉗子夾著烤肉籤；按住按鈕烤棉花糖，指針落在「完美」時放開，烤焦的話牠會抱著棉花糖縮回帳篷
  - 每完成一個營地，營火邊就多一支棉花糖；沒有棉花糖時可以用練習模式（不計分）
  - 帳篷的樣子跟著公共裝備的進度，營火大小跟著出發倒數，越接近出發日火越旺
  - 出發前 9 天內會顯示營火倒數的日期列
- **分享**：把公共清單或個人行李的勾選狀態複製成文字，貼到 LINE 群組；手機上也能用分享選單直接傳

「寄居帳」是這個網頁的原創角色。

## 部署到 GitHub Pages

1. 在 GitHub 建立新的 repository，例如 `camping-checklist`，設成 **Public**
   （免費方案的 GitHub Pages 只支援 Public repository）
2. 在 repository 頁面按 **Add file → Upload files**，把上面的檔案拖進去，按 **Commit changes**
3. 到 **Settings → Pages**，在 **Build and deployment** 的 **Source** 選 **Deploy from a branch**
4. Branch 選 `main`，資料夾選 `/ (root)`，按 **Save**
5. 等一到兩分鐘，網址會是 `https://你的帳號.github.io/camping-checklist/`

更新檔案時，一樣用 **Add file → Upload files** 上傳同名檔案就會覆蓋，幾分鐘後網站自動更新。

### （選用）讓分享預覽圖穩定顯示

LINE、Facebook 抓預覽圖時通常需要完整網址。部署完成後，把 `index.html` 裡這一行：

```html
<meta property="og:image" content="og-image.png">
```

改成：

```html
<meta property="og:image" content="https://你的帳號.github.io/camping-checklist/og-image.png">
```

LINE 會快取舊的預覽圖，換圖後可能要過一段時間才會更新。

## 使用方式

1. 打開網址，在「山路」看整體進度，點營地或下方的營地卡片進入那一區
2. 在「清單」一項一項打勾，上方的出發體力隨時看得到還缺什麼
3. 勾完一區就到「營火」烤棉花糖
4. 需要回報時，到「分享」複製文字貼到 LINE

工作分配請在群組裡自行討論，這個網頁只負責清單確認。

## 資料存在哪裡

- 勾選紀錄、烤棉花糖紀錄存在瀏覽器的 localStorage，只在那一台裝置、那一個瀏覽器裡，不會傳到任何伺服器
- 每個人打開網址，看到的都是自己的勾選
- 在 LINE 內建瀏覽器和在 Safari 打開，紀錄是分開的；清除瀏覽資料後紀錄會消失
- 舊版網頁的勾選紀錄會沿用，更新後不用重勾

## 修改清單內容

編輯 `index.html` 裡 `window.CAMP_DATA = { … }` 那一段（上方有「清單內容」註解）：

- `startDate`：出發日期，格式 `年-月-日`，例如 `2026-11-14`
- `title`、`subtitle`：標題與副標
- `people`、`tents`：人數與帳篷數，只用在標題文字
- `stickers`：封面的三張貼紙
- `camps`：四個營地的名字
- `needs`：出發體力的狀態名稱和顏色
- `asks`、`shared`、`cook`、`me`：四區清單；每項有 `id`、`name`、`note`、`need`，炊具另外有 `tag`
  - `need` 填 `needs` 裡的代號（`cold`、`wet`、`hungry`、`dark`、`hurt`、`messy`、`unknown`），代表沒帶會怎樣

注意：

- 每個 `id` 不可以重複，勾選紀錄靠 `id` 記住
- `**文字**` 會顯示成粗體
- 改了某項的 `id`，那一項原本的勾選紀錄就會消失

## 本機預覽

直接用瀏覽器打開 `index.html` 就能使用。
